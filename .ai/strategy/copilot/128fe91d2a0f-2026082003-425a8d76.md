## Findings

### F-1 — No shadow window data available (all families)
Without runtime evidence, money-weighted net P&L after costs cannot be assessed. The governance thresholds in `strategy_lab.py` (`MIN_EVALUATION_WINDOWS=3`, `MIN_EVALUATION_TRADES=8`, `MIN_PROFIT_FACTOR=1.10`) exist but have no current data attached to this cycle. **Required before any promotion: three evaluation windows, eight qualifying trades, profit factor ≥ 1.10 on each chain.**

### F-2 — forecasted_positive_net_edge: missing model metadata
`forecasted_positive_net_edge` in `cross_chain_strategy_signals.py` (~line 228) produces a composite eligibility score but does not declare:
- feature set available strictly before decision time;
- model family;
- time-ordered train/validation/test split;
- calibration metric (Brier score, log loss).

Without these, out-of-sample performance cannot be verified and lookahead leakage cannot be ruled out. **Action: IMPROVE — add model card metadata and calibration check before shadow promotion.**

### F-3 — new_liquidity_quality: no sellability gate at evaluation time
`new_liquidity_quality` passes a token as `eligible=True` based on pool age and liquidity depth, but does not obtain a sell-side quote before emitting the signal. Honeypot mechanics, transfer taxes, or one-sided liquidity can cause exit failures not modelled at signal time. **Action: IMPROVE — add a sellability probe (sell-quote attempt) as a hard gate.**

### F-4 — Fee model currency unverifiable without live data
All signals rely on `MarketFeatures.estimated_fees_bps` via `net_edge_bps`. The source of fee estimation is not visible in the signal layer. EVM base-fee volatility and Solana priority-fee market conditions change frequently. Stale cost models cause overestimated net edge. **Action: RESEARCH_MORE — compare executed vs estimated fees on last 100 shadow trades per chain; update model if bias exceeds 2 bps.**

### F-5 — learned_route_replication: execution leakage risk under MEV competition
`learned_route_replication` gates on `route_pattern_confidence > 0.6` and net edge threshold, but does not model latency, MEV front-running or priority-fee variance at signal evaluation time. Route advantage observed historically can be entirely consumed by competition at execution time. **Action: SHADOW_MORE — five evaluation windows tracking simulated vs executed net P&L.**
