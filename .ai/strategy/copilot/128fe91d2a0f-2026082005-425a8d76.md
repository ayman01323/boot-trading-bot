## Proposals

### PROP-COPILOT-001 — Liquidity-Confirmed Momentum: stale-quote guard missing
**Action:** IMPROVE | **Confidence:** 0.80 | **Chains:** SOLANA, EVM

**Finding:** `CrossChainStrategySignal._evaluate_signal` does not enforce a maximum `quote_age_ms` bound before computing net edge. `MarketFeatures.validate()` confirms `quote_age_ms >= 0` but imposes no chain-specific ceiling (e.g. 800 ms Solana, 3000 ms EVM). A stale quote can pass the positive-edge gate with inflated apparent `gross_edge_bps`, leading to real slippage exceeding the forecast `slippage_bps` and eroding net P&L.

**Files:** `learnerbot/cross_chain_strategy_signals.py`, `learnerbot/market_feature_adapter.py`

**Shadow test:** Inject `MarketFeatures` with `quote_age_ms` above chain threshold and positive `gross_edge_bps`. Verify rejection. Compare slippage_cost and execution_failures over a 48 h SHADOW window.

**Evidence needed:** `strategy_lab_windows` rows for slippage_cost vs quote_age correlation.

### PROP-COPILOT-002 — Profitable-Wallet Cohort Pattern: research pipeline not scheduled
**Action:** RESEARCH_MORE | **Confidence:** 0.72 | **Chains:** SOLANA, EVM

**Finding:** `strategy_lab_research.py` defines `PUBLIC_RESEARCH_TOOLS` (Dune, Etherscan API V2, DEX Screener, DefiLlama, Jupiter) and `FORECAST_RESEARCH_SPEC` but no scheduled process materialises cohort data into `strategy_lab_registry`. Without a multi-wallet, multi-regime cohort study, route/timing strategies derived from wallet behaviour are unsupported.

**Requirement:** Cohort must have ≥ 50 resolved trades per wallet per chain, profit factor ≥ 1.10 in ≥ 3 distinct 30-day windows, and money-weighted net P&L positive after estimated gas/fees. Raw win rate is explicitly excluded as a selection criterion.

**Research tools:** Dune (wallet cohort query), Etherscan API V2 (EVM history reconstruction), DEX Screener API (pool/volume context), DefiLlama (regime conditioning).

**Shadow test:** Register SHADOW strategy from derived cohort features. After ≥ 8 shadow trades evaluate profit factor ≥ 1.10 and largest_loss controls.

### PROP-COPILOT-003 — Forecast Calibration pipeline absent
**Action:** RESEARCH_MORE | **Confidence:** 0.75 | **Chains:** SOLANA, EVM

**Finding:** `MarketFeatures` carries `forecast_positive_edge_probability`, `forecast_expected_net_bps` and `forecast_uncertainty` fields, but:
- No calibration metric (Brier score / log-loss) is computed over shadow trade outcomes.
- No time-ordered train/validation/test split is enforced.
- `forecast_uncertainty` defaults to `1.0` (maximum uncertainty) but no consumer implements an abstain rule when uncertainty is high.

A miscalibrated forecast silently degrades net P&L by passing false-positive signals through the edge gate at elevated rate.

**Shadow test:** Over 72 h on both chains: log `(forecast_positive_edge_probability, forecast_uncertainty, realised_net_profit > 0)` per shadow trade. Require Brier ≤ 0.20 and log-loss ≤ 0.50. Implement abstain rule: skip signal when `forecast_uncertainty > 0.4`.

**Files:** `learnerbot/shadow_strategy_executor.py`, `learnerbot/market_feature_adapter.py`

---

### PROP-COPILOT-004 — New-Liquidity Quality Strategy: pool_age_seconds unused as primary filter
**Action:** SHADOW_MORE | **Confidence:** 0.68 | **Chains:** SOLANA, EVM

**Finding:** `pool_age_seconds` is a `MarketFeatures` field but no registered strategy family uses it as a primary entry filter. Early-pool momentum with quality gating (`sellability_score ≥ 0.7`, `liquidity_score ≥ 0.5`, `pool_age_seconds ∈ [300, 7200]`, `net_edge_bps > 50`) may offer differentiated edge from existing strategies.

**Risk note:** New-pool strategies carry elevated rug/exit risk. Sellability and liquidity gates must never be weakened. Largest-loss monitoring is paramount.

**Shadow test:** Register SHADOW with the above parameters. Run ≥ 3 evaluation windows. Require profit factor ≥ 1.10. Retire immediately if largest_loss dominates gross_profit. Do not promote without ≥ 8 qualifying shadow trades.

**Research tools:** DEX Screener API (pool discovery), Dune (historical pool-age vs outcome distribution), Jupiter (Solana quote/sellability validation).
