# SiBot Telegram quick reference

Use the `🤖 SiBot / SiMo` button in the Telegram main menu.

- Strategy ON + LIVE AUTO OFF = SHADOW mode, no automatic signing.
- `/live on CONFIRM` then `/sibotstart CONFIRM` = request SiBot LIVE AUTO. MASTER LIVE/AUTO platform gates must also be ON.
- `/sibotstop` = no new copied entries; existing LIVE SiBot positions continue safety/leader-exit monitoring.
- `/sibotreport` = capital and P&L by chain plus overall totals.
- `/sibotleaders` = current SiMo leaders.
- `/sibottop20` = current Top-20 profitable wallet ranking.
- `/sibotsettings` = current settings.
- `/sibothelp` = full strategy explanation.
