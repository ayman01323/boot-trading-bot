# v1.9 Telegram Wallet and Automatic Route Guide

## Recommended first setup

1. `/walletcreate CONFIRM`
2. Fund the returned address with a very small amount of BNB (BSC) or ETH (Base).
3. `/assets bsc`
4. `/setautosize 0.001`
5. `/setautoprofit 0.0001`
6. `/autoprep bsc 0.005 CONFIRM`
7. Keep `/mode shadow` initially and inspect `/opportunities`.
8. When satisfied with live quotes/simulations: `/mode armed`
9. `/live on CONFIRM`
10. `/autotrade on CONFIRM`

Automatic execution needs all three gates: ARMED + LIVE + AUTOTRADE.

## Wallet commands

- `/wallet` — wallet status and setup help.
- `/walletcreate CONFIRM` — server creates and encrypts a dedicated trading wallet.
- `/walletimport 0xPRIVATEKEY CONFIRM` — private-chat-only fallback. Never use a seed phrase. The bot refuses to store the key unless Telegram deletes the incoming message first.
- `/assets bsc` / `/assets base` / `/assets all` — show native and discovered/tracked non-zero assets.

## Automatic route commands

- `/auto` — status and safety gates.
- `/opportunities` — current exact routes, quote/simulation/liquidity/atomic flags.
- `/autoprep bsc 0.005 CONFIRM` — wrap capital and approve only the bounded amount.
- `/setautosize 0.001` — exact route quote/trade input.
- `/setautoprofit 0.0001` — minimum expected net wrapped-native profit.
- `/autotrade on CONFIRM` / `/autotrade off`.

## What “automatic buy/sell” means here

For an arbitrage route, the bot does not buy a token and leave an open position. It executes the complete learned/current cycle in one router transaction, for example:

`WBNB -> USDT -> TOKEN -> WBNB`

The output floor is set above the starting WBNB by estimated gas plus the configured minimum net profit. If that output is not available at execution time, the swap reverts instead of deliberately completing a loss-making route (gas can still be spent on a reverted transaction).

## Asset display limitation

EVM JSON-RPC has no standard method that enumerates every ERC-20/BEP-20 token owned by an address. v1.9 therefore combines configured tokens, tokens seen in its own trade/scanner files and best-effort recent Transfer logs. Unknown old/spam tokens may not appear.
