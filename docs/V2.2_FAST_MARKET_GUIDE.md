# v2.2 Fast Market Guide

The fast scanner runs independently from historical wallet learning. It maintains a V2 pair graph, bootstraps configured liquid-token pairs with `factory.getPair()`, constructs only complete WBASE-A-B-WBASE triangles, exact-quotes them, checks 2x-size price impact and writes passing routes to the direct feed.

Monitor:

```bash
journalctl -u learnerbot -f
cat CSVbot/auto/fast_market_status.csv
head -20 CSVbot/auto/direct_market_rejections.csv
head -20 CSVbot/auto/direct_market_opportunities.csv
```

A normal safe result can be `direct=0`. Do not reduce safety thresholds just to make a route appear.

Before live automatic signing, require Telegram `/opportunities` to show a wallet-specific `my_sim=true` route. The scanner result alone is not permission to sign.
