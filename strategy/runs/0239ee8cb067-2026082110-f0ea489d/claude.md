# Claude strategy review

Evidence this cycle is architecture-only (evidence_status=MISSING_RUNTIME_FORENSICS, bytes verified); no runtime P&L, canary or LIVE-readiness claims are made. The repo already implements a genuinely money-weighted, cost-aware, agent-gated SHADOW->CANARY->PROBATION->ACTIVE lifecycle for EVM strategies (strategy_canary.py, cross_chain_strategy_signals.py, shadow_strategy_executor.py). However static reading found: (1) Solana's shared quote-time feature adapter is hardcoded to zero edge/liquidity/sellability, so no Solana strategy can reach eligible=True through the common evaluator; (2) strategy_canary.py's realized-trade profit-factor promotion ladder scopes itself to EVM only and has zero Solana logic, even though Solana live order submission is independently reachable from the main loop today via a separate per-user gate; (3) neither the SHADOW scorecard nor the realised loss-forensics export implements a STRATEGY/MARKET vs EXECUTION/INFRASTRUCTURE taxonomy, so the objective's required separation is not yet a first-class field anywhere; (4) a stale 3-agent set in strategy_canary.py omits 'claude' relative to the newer four-agent master contract (currently masked, not exploitable); (5) self-applying, one-time migration files hardcode LIVE/AUTO=true for one specific Telegram account on Polygon and Solana, independent of any AI review outcome, which is a fact operators should be aware of when reading the READMEs' 'MASTER LIVE/AUTO OFF by default' framing. Proposals below target Strategy Lab/SHADOW-only files per policy; the live-arming and objective-text findings are reported as evidence gaps rather than code-change proposals because the relevant files sit outside the SHADOW auto-edit allow-list.

## IMPROVE — Cross-chain economic evaluator (all 7 evaluators in cross_chain_strategy_signals.py)
The review objective explicitly includes 'failed executions' in durable net P&L. The current bps model implicitly assumes every scored opportunity executes cleanly, which overstates expected edge on both chains, but by different amounts given each chain's distinct failure mechanics.

## IMPROVE — Strategy Lab shadow scorecard (all strategies)
docs/STRATEGY_LAB.md's own hourly-review checklist asks 'which losses came from strategy selection versus execution' but no deterministic field answers that question today; it is currently re-derived from free text each cycle by whichever AI is reviewing.

## RESEARCH_MORE — Solana strategy promotion path (all Solana-eligible strategies)
Solana can already execute real trades through a path independent of the EVM canary ladder, but has neither a working quote-time SHADOW evaluator nor a realized-trade profit-factor bar analogous to EVM's. This is a structural blind spot for comparing Solana and EVM strategy quality as the review objective requires.
