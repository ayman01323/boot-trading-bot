# Claude strategy review

Evidence for this cycle is architecture-only (.strategy_claude/evidence.json is a MISSING_RUNTIME_FORENSICS placeholder with generated_epoch=0, no trade_latency/infrastructure/P&L data), so no measured profitability, latency, or canary-readiness claims are made. Code review of learnerbot/ shows a chain-agnostic net-edge signal framework (cross_chain_strategy_signals.py) gating on fees/slippage/impact/latency-reserve, with a well-structured SHADOW->PROMOTION_CANDIDATE->CANARY promotion pipeline (strategy_lab.py, strategy_canary.py) that never auto-promotes. The main asymmetry found is between Solana and EVM: Solana's shared-signal adapter (market_feature_adapter.py::load_solana_market_features) hardcodes gross_edge_bps/liquidity/sellability to 0 (needs_quote_feature_adapter=True), unlike EVM's EXACT_QUOTE_AND_SIMULATION basis, and it is unconfirmed whether this placeholder feeds the SHADOW profit-factor gate or whether Solana promotion instead uses the real net_sol ledger in solana_sibot.py::evaluate_position. EVM also lacks an evaluate_position-equivalent single net-P&L-after-gas ledger, and lacks the per-stage latency instrumentation that Solana has via execution_latency.py/solana_execution_latency_patch.py. These gaps limit how confidently Solana and EVM economics can be compared chain-specifically, independent of strategy quality.

## RESEARCH_MORE — Cross-chain Strategy Lab signal evaluators (all 7 in cross_chain_strategy_signals.py) as applied to Solana opportunities
If Strategy Lab's Solana SHADOW profit-factor evaluation is fed by the placeholder MarketFeatures (edge/liquidity/sellability = 0) rather than a real quote-derived figure, a Solana strategy could statistically clear the 1.10 profit-factor gate without reflecting real slippage, price impact, or sellability risk, directly undermining the durable money-weighted NET P&L objective on Solana specifically. This was not confirmed by tracing every call site, so it is raised as a question to resolve, not an established defect.

## IMPROVE — EVM live execution net P&L accounting parity with Solana
Without a single authoritative EVM net-P&L-after-gas figure comparable in structure to Solana's evaluate_position, chain-specific NET P&L comparisons required by this review's objective (Solana vs EVM using chain-specific economics) cannot be made cleanly from code alone, and any future runtime evidence comparing the two chains risks comparing differently-derived numbers.

## IMPROVE — Execution latency instrumentation parity with Solana
The review objective requires comparing Solana and EVM using chain-specific economics including latency, and CLAUDE.md's engineering-audit process requires chain-by-chain trade_latency evidence with p50/p95 and RPC round-trip; without equivalent EVM instrumentation this comparison structurally favors/only-covers Solana.

## KEEP — SHADOW -> PROMOTION_CANDIDATE -> CANARY promotion pipeline
This staged, non-auto-promoting gate structure with escalating profit-factor thresholds and AI-council sign-off is a sound structural control against premature capital exposure to unproven strategies; no evidence was found of it being weakened.
