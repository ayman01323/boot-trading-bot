# Claude strategy review

Architecture-only review (no runtime forensics supplied). The strategy engine (learnerbot/cross_chain_strategy_signals.py, strategy_lab.py) and execution paths (learnerbot/live_executor.py for EVM, learnerbot/solana_live_executor.py + solana_execution_efficiency_patch.py for Solana) show disciplined cost-aware gating: net-edge/liquidity/sellability thresholds before eligibility, gas-reserve-inclusive min-out floors, capped total-fee ratios and profit-share fee caps on Solana, and fail-closed pre-broadcast simulation plus on-chain-proof-required execution reconciliation before any exit is marked complete. The most recent strategy-relevant commit (fba36d7) hardened the Solana emergency-exit circuit breaker by persisting backoff state and adding an operator-confirmed, hard-capped manual override -- a genuine reliability improvement with no weakening of the impact ceiling invariant. The main gaps found are observability/measurement gaps, not missing controls: (1) quote-vs-actual slippage/fill-quality is never computed despite both quoted and actual amounts being stored in the same execution-receipt rows on Solana, and EVM's audit trail never logs the actual delivered output at all; (2) strategy-caused loss and execution/infrastructure-caused loss are tracked in separate counters (exit_reason_counts vs exit_circuit_status_counts) with nothing merging them into one reconciled attribution figure, which is exactly the separation this review's objective requires. Neither gap implies unsafe behavior today; both limit how precisely durable net P&L can be attributed once real trading data exists. No live/runtime evidence was available this cycle to validate any of this against actual outcomes.
