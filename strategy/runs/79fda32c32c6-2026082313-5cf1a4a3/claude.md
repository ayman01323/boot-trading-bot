# Claude strategy review

Architecture-only review (no runtime forensics supplied). The system is a wallet-copy-trading + cross-venue arbitrage bot with a shared 7-evaluator signal layer (learnerbot/cross_chain_strategy_signals.py) feeding both EVM and Solana execution under a SHADOW->PROMOTION_CANDIDATE->ACTIVE evidence-gated pipeline (learnerbot/strategy_lab.py), not a historical-backtest engine. Risk controls are layered as sequential patch modules with a self-check asserting wrapper integrity at import; recent commits 3a8a640/b5057b5 closed a real bug where a healthy platform profit-factor previously bypassed the stuck-position systemic breaker entirely. Execution has fail-closed pre-trade gates on both chains (EVM: simulate_cycle + local eth_call prebroadcast; Solana: Jupiter round-trip preflight capping combined price-impact+slippage at 500bps, simulated reserve guard). Two structural gaps found: Solana's shared-signal market features (gross_edge, liquidity_score, sellability_score) are explicitly hardcoded to zero pending a documented 'quote feature adapter' gap, meaning the cross-chain signal layer cannot currently discriminate real opportunities on Solana; and EVM lacks Solana's reverse-quote sellability/honeypot preflight, with thin nonce management and no RPC failover on either chain. None of these can be tied to realized net P&L this cycle because no runtime/live evidence was supplied.
