SoGrok now supports a fail-closed `LIVE_READINESS` mode for native SOL. Use `/groklivecheck on CONFIRM` in the dedicated Grok Telegram bot. This mode performs fresh public Jupiter USDC→SOL entry, full SOL→USDC reverse, and 3× exit-stress route checks, then emits `LIVE_READY` or `LIVE_PREFLIGHT_REJECT`. It never loads a private key, never signs a transaction, and never broadcasts a transaction. See `docs/LIVE_READINESS.md` for limits and behaviour.
